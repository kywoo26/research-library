The text-to-SQL pipeline still limps along for most steps because non-reasoning calls fall back to the reasoning model, but SQL generation returns `None` after retries and the graph enters the `unconstructable_sql_response` repair loop, so the README quickstart question never gets a complete answer.\n\n## Environment\n\n- Deployment: Docker Compose (auto-ontology latest `main`)\n- Endpoint: `https://integrate.api.nvidia.com/v1`\n- Models: `nvidia/nemotron-3.5-lightning-30b-a3b` (non-reasoning), `nvidia/nemotron-3.5-super-vl-120b-a12b` (reasoning)\n- `langchain-nvidia-ai-endpoints==1.4.3`\n\n## Symptoms\n\nBackend log, on every structured-output step (`QuestionIntentModel`, `QuestionExtractionModel`, `TableRelevanceModel`, `SQLGenerationModel`, …):\n\n```\nERROR auto_ontology.utils.llm_invoke: Unexpected error on attempt 1/3 for SQLGenerationModel:\nException: [400] unknown field `guided_json`, expected one of `greed_sampling`, `use_raw_prompt`,\n`annotations`, `backend_instance_id`, `token_data`, `max_thinking_tokens`, `cache_salt`, `extra_fields`,\n`metadata_upload`, `prefill_worker_id`, `decode_worker_id`, `dp_rank`, `prefill_dp_rank`, `agent_hints`,\n`request_timestamp_ms`, `routing_constraints`, `router`\n```\n\n- Every non-reasoning structured call fails 3× fast, then falls back to the reasoning model → each pipeline step takes ~2 min instead of seconds.\n- `sql_from_semantic` exhausts its own 3-attempt loop (\"LLM returned None after 3 attempts\") → `unconstructable_sql_response` → a full repair re-run that fails the same way.
