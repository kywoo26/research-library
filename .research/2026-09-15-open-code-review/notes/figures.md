# 고정한 공식 소스의 그림

- OCR README Highlights (imgs/highlights-en.png): Alibaba가 내부 사용·task·다운로드·token 비용·benchmark를 한 그림에 표시한다. 원본을 직접 열었다. 이 글은 지표 수치를 재인용하지 않는다. https://github.com/alibaba/open-code-review/blob/216dcf513593055a70165f793e96b52589d71b1b/imgs/highlights-en.png
- OCR README Benchmark (imgs/benchmark-en.png): SOURCE 열에 Open Code Review v1.3.1, Open Code Review v1.8.7, Claude Code v2.1.169, Codex v0.140.0이 표시된다. metric은 F1, precision, recall, avg time, avg token이다. 원본을 직접 열었다. 현재 경로들에 성능 순위를 붙이지 않기 위해 수치 plot은 재사용하지 않는다. https://github.com/alibaba/open-code-review/blob/216dcf513593055a70165f793e96b52589d71b1b/imgs/benchmark-en.png
- Anthropic Code Review pipeline: 공식 code-review.md의 alt는 Find → Verify → Rank → Post 흐름을 설명한다. SVG 원본은 열지 않았으므로 내장하지 않는다. 본문 단계는 공식 문서의 How reviews work에 근거한다.
- 이 글의 managed·입력·후처리·예산·delegation·도입·trial 판: 공개 소스의 원본 도식을 복제한 것이 아닌, 고정한 코드·문서에서 추적한 흐름과 이 글의 판단을 도식화한다.
