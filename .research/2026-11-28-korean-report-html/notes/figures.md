# 그림 기록
- NN/G How People Read Online: gaze plot·heatmap 사례. 읽기 유형을 설명하지만 한국어 문서 독자 실험은 아니다. 본문에 원본 이미지를 재게시하지 않는다.
- 자체 개념도 예정: 독자 과제와 표현 형식의 대응, 정비 절차→분석 설명의 한국어 변형. 원문 실험 결과로 가장하지 않는다.

- 우아한형제들 Redis §4 1차 실험 바이트 크기 표: 단건 JSON/Fory/Proto=243/190/155, 객체 200개 List=49,240/25,077/31,884. 조건: 압축 없음. 원문 표의 값만 옮겨 내장 Chart.js와 HTML table로 시연. 원문은 이 표 아래 막대 그림도 있으나 이번 저자는 원자료 표를 읽었다.
- 자체 SVG 표지: 독자 과제(이유 이해/조건별 결과/같은 기준 비교)와 문단/상태도/차트·표를 대응. 순서나 실험 효과를 뜻하는 화살표 없음.
- 자체 SVG 장8: 기존 OpenCodeReview 문단의 보호 주제/직접 반박 분기를 그린 편집 예. 유지 상태는 사실 확인을 뜻하지 않음. 완전한 도구 구현이나 재현 결과가 아님.
- 한국어·영어 실증 논문과 도구 평가의 원본 그림은 재게시하지 않았다. 전문을 열지 못한 연구의 차트 값을 추정하지 않았다.
