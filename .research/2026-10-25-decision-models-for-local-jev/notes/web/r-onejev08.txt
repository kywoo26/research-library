OneJev1.6-0.8B is the 0.8B model of OneJev 1.6, a multimodal System One decision model. Give it a screenshot, a photo, a video or plain text along with a few typed questions, and it returns a calibrated probability for every option in a single forward pass. It averages the weights of three full fine-tunes of [Qwen/Qwen3.5-0.8B](https://huggingface.co/Qwen/Qwen3.5-0.8B), trained on 390,000 to 440,000 questions drawn from real agent runs, videos, images and the training splits of public decision datasets.

## Decision Index

On the public part of [Decision Index 0.3](https://huggingface.co/spaces/multimodalart/jev-decision-index) (37 benchmarks, 140,178 requests, run and scored with the board's own kit), OneJev1.6-0.8B scores 48.82, up from 42.71 for OneJev1.5-0.8B. That is the highest of any model up to 2.5B parameters on the board, and it leads its class in all five areas.

## Quick start

```bash
uv venv -p 3.12 && source .venv/bin/activate
uv pip install flide torchvision
flide serve --model OmniJev/OneJev1.6-0.8B
```

In another terminal, run this example with your own `screenshot.png`:

```bash
IMG=$(base64 -w0 screenshot.png)
curl http://localhost:8000/v1/systemone -H "Content-Type: application/json" -d @- <<EOF
{
  "state": {"task": "Pay the open invoice from ACME", "screen": "<image:1>"},
  "media": [{"type": "image", "data": "data:image/png;base64,$IMG"}],
  "questions": {
    "done": {"type": "noul", "instructions": "The invoice has been paid"},
    "next": {"type": "choice", "instructions": "What should the agent do next?",
             "criteria": {"click": "click an element", "type": "type text", "scroll": "scroll", "stop": "stop"}},
    "progress": {"type": "score", "instructions": "How far along is the task?",
                 "criteria": ["not started", "halfway", "almost done", "done"]}
  }
}
EOF
```

`answers.done.noul` is the probability of yes, `answers.next.probabilities` gives one probability per option and `answers.progress.score` is the expected level.

[Flide](https://github.com/OmniJev/Flide) serves TypeSafe's System One API plus a `media` field for images and video. More examples are on [GitHub](https://github.com/OmniJev/OneJev).
