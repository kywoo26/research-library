OpenCodeReview가 코드 리뷰의 실행 조건을 관리하는 방식

OpenCodeReview는 diff를 고르고 LLM 리뷰를 실행하는 Alibaba의 CLI다. 자체 리뷰로 시작하되 파일 선택·규칙·실패 기록을 별도로 관리해야 할 때 OCR을 시험하는 편이 낫다는 판단이다. 실행 조건을 코드로 관리해도 결함 판단은 LLM에 남으므로, 정확도와 비용은 같은 PR에서 확인해야 한다.

Alibaba 개발자의 OpenCodeReview 공식 코드·문서(main 216dcf5, 최신 릴리스 v1.13.3)와 OpenAI·Anthropic의 공식 코드·제품 문서를 읽었다. 2026-11-02 기준 전면 갱신이다. 비교와 도입 판단은 아래 출처를 종합한 해석이다.

공개 성능표로 현재 경로의 우열을 정할 수는 없다

현재 실행 경계는 고정한 코드와 공식 문서로 확인했다. 현재 버전들의 정확도와 비용을 비교하는 측정은 별도다.

  • Alibaba의 성능 주장은 저자 보고다. README의 Benchmark 그림은 OCR와 Codex·Claude의 특정 과거 CLI 버전을 표시한다. 그 비교를 현재 내장 리뷰·공식 plugin·cloud 서비스의 결과로 옮겨 쓰지 않는다. 고정한 그림의 표기
  • 실제 리뷰는 실행하지 않았다. 현재 같은 PR에서 LLM을 호출하거나 발견을 사람에게 채점받지 않았으므로 정확도 우열·비용 절감률은 판단하지 않았다. trial로 유효 발견과 누락을 함께 확인한다.
  • 코드 경로와 운영 결과를 구분했다. selection·grouping·filter·budget·resume 설명은 구현을 읽은 결과다. provider 장애, 실제 과금, 호스트의 지시 이행률과 장기 운영 안정성은 이 조사로 확인하지 않았다.
  • 서비스 내부는 공개된 설명까지다. Claude Code Review의 정적 검토와 Ultrareview의 재현·검증 설명은 Anthropic의 제품 설명이다. 내부 agent 수·prompt·검증 성공률을 추정하지 않는다.
  • 유지 활력의 수치를 단정하지 않았다. 최신 릴리스와 CI·unit test 정의는 열었지만 shallow checkout으로 commit 빈도·기여자 분포·응답 속도나 미래 지원 기간을 판단하지 않았다.
