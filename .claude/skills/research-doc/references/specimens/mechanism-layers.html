effort 단계는 Claude 가 일하는 방식을 바꾸는 신호다

단계를 올리면 Claude 는 더 자주 생각하고, tool call 을 더 하고, 스스로 확인하고 판단하는 일을 늘린다. 토큰 상한이 정해지지는 않아서 낮은 단계에서도 충분히 어려운 문제에는 생각한다.

블로그 §What is effort?

작업의 모양이 바뀐다
  • 테스트를 한 번 더 돌린다
  • 다른 방법으로 답을 맞춰 본다
  • 말하지 않은 부분을 스스로 정한다
  • 원문에는 이 그림이 없다. 세 자료가 각자 설명한 층을 한 그림에 모았고, 어느 층이 어느 행동을 낳는지는 원문이 나누지 않는다.

Claude API 문서 §Effort levels: “Effort is a behavioral signal, not a strict token budget. At lower effort levels, Claude still thinks on sufficiently difficult problems, but thinks less than it would at higher effort levels for the same problem.”
