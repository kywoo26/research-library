Claude Code 는 세 곳을 차례로 보고 처음 정해진 effort 단계를 쓴다

세션의 단계는 아래 순서로 정해진다. skill 과 subagent 의 frontmatter 는 도는 동안 그 결과를 덮는다.

// Claude Code 문서 §Adjust effort level. 위에서부터 보고 처음 정해진 것을 쓴다
1 명시적 선택    CLAUDE_CODE_EFFORT_LEVEL · --effort · 세션의 /effort
  └ 없으면
2 저장한 설정    모델마다 저장한 단계 · settings 의 effortLevel 키
  └ 없으면
3 모델의 기본값  Opus 5.5 · Sonnet 5.5 · Haiku 5.5 → medium
                 Opus 4.7 → xhigh, 그 밖의 effort 지원 모델 → high

// §Set the effort level
skill · subagent frontmatter 의 effort   도는 동안 세션 단계를 덮는다. 환경 변수는 못 덮는다
// §Adjust effort level
/effort 에서 Enter                       2 에 저장한다
/effort 에서 s                           이번 세션에만 쓴다 (v2.1.257 이상)
max                                      환경 변수로 정하지 않으면 이번 세션에만 쓴다
  • 1 안의 셋 사이 순서는 이 trace 가 정하지 않는다.
원문

§Adjust effort level: “Claude Code resolves the session's effort level in this order, taking the first that applies:” “3. The model's default effort: `high` on every model that supports effort, except that Opus 5.5, Sonnet 5.5, and Haiku 5.5 default to `medium`, Opus 4.7 defaults to `xhigh`”

§Set the effort level: “Frontmatter effort applies when that skill or subagent is active, overriding the session level but not the environment variable.”
